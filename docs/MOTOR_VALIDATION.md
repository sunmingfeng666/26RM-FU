## 主机测试

在两个分支分别执行 `python tools/test-motor.py`，每次通过 32,052 项断言：

- 同时编译原样保存的旧大符/小符 `tim_task.c` 与旧 `all_init.c`，只在主机编译时重命名符号。
- 10,000 个大符周期和 1,000 个小符周期：同样的时间、初始参数和反馈输入下，目标 rpm、PID 浮点输出和发送电流 raw 逐步一致。
- 大符随机参数范围、总减速比 57、小符斜坡与 570 rpm 终点、积分/输出限幅。
- 上电按住不启动、20 ms 消抖、长按不重复切换、同模式重选不重置、大小符切换、双键停止及半松开不误启动。
- 无反馈启动被拒绝、100 ms 反馈超时、时钟回绕、bus-off、CAN 发送失败、恢复后等待新的按键。
- 实际 CAN 适配层的 ID/DLC 过滤、速度/电流字节序、`0x200` 四通道编码、其他三通道为零、停止时撤销待发报文。
- 修改 `g_motor_debug` 快照不产生控制动作。

旧源码快照与原文件的逐字节一致性和 SHA-256 记录在 `fu_motor/tests/SHA256.json`。测试引用保留在仓库，之后运行测试不依赖原始 `E:/BaiduSyncdisk/老` 目录。

两个分支的 `flash.ps1 -ExpectedBoard motor -ExpectedConfiguration Debug -PlanOnly` 均通过，定位到对应分支 `build/motor-Debug/EnergyFirmware.elf`，芯片为 STM32F103C8。此检查未扫描 USB 或连接硬件。
