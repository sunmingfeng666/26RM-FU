# ESP32-C3 电机联动：最终软件候选

2026-10-31。此记录对应本轮最终源码与交付清单。用户选择先完成代码、稍后接线；本次没有下载新联动固件，没有启动电机，实物三端联动尚未验证。此前较早的候选快照和其他板卡 CAN 测试记录继续保留，本记录单独给出最终软件证据。

## 构建

| 目标 | 结果 | Flash 使用 | 静态 RAM |
|---|---|---:|---:|
| 屏幕 nicemcu_motor_now | 干净构建通过 | 1,043,373 / 1,310,720 B | 45,788 B |
| 电机接收 motor_esp32c3 | 干净构建通过 | 736,880 / 1,310,720 B | 38,084 B |
| 原灯板接收 XIAO S3 | 干净构建通过 | 696,897 / 3,342,336 B | 43,632 B |
| 电机 F1 motor-Debug | 两分支干净构建通过 | 31,364 / 65,536 B | 3,080 / 20,480 B |
| 原纯灯板屏幕 nicemcu | 单独构建通过 | 保留兼容配置 | 未启用电机联动 |

F1 两个分支的 bin 完全相同。ESP32 静态 RAM 不含 Wi-Fi/队列/任务等运行时申请；屏幕另有 80 KiB LVGL 固定池和 38,400 B DMA 缓冲。没有用这些数值推断实际堆余量或射频稳定性。

C3 的 USB 调试输出等待设置为 1 ms，避免电脑串口背压阻塞转发主循环；最终设置已重新完成 C3 干净构建。

交付目录为 `remote/artifacts/motor-now-20261031/`，含三端固件、F1 ELF/HEX/BIN/MAP、各 ESP32 分区偏移及长度/SHA256 清单；由 `remote/tools/package_motor_now.py` 冻结。候选代码和固件的最终摘要见交付目录 `manifest.json`，该脚本不访问硬件。

## 已通过的软件验证

- `tools/test-motor.py`：两分支各 **32,099** 项检查。包括旧速度目标回归、按键、CAN、真实 UART 回调/队列、心跳超时、重复/过期/溢出/错误输入、按键接管、温度/超速、控制周期异常时清理旧转矩帧，以及远程初始化失败后本地按键仍可用。
- `tools/test-motor-link.ps1`：**13,560** 项检查。包括明确编码与 CRC、去重/乱序、STOP 屏蔽迟到 START、同模式重新开始、双向证明、单向失败、重启、C 板确认和低压联动。补测旧按键状态不能误判为新接管；等待 F1 自己确认后才维持远程联动。按键保持导致新 START 被拒绝时，撤销灯板运行并保留有效本地运行。
- `tools/test-motor-now.ps1`：**1,228** 项检查。包括无线外层 16/56 字节长度/版本/CRC、逐字节损坏、C3 启动绑定、重启旧包丢弃、三端重启、双向/单向断开、本地接管和恢复不自动启动，使用真实 F1 服务端、屏幕客户端及编解码器。
- `tools/test-motor-radio.ps1`：实际 `remote_radio.cpp` 通过双端点 **23** 项、单电机端点 **16** 项检查。只初始化/注册一次回调，两组 MAC 使用独立有界队列，目标地址正确，过期包/队列溢出被处理。辅助 MAC/队列初始化完毕后通过原子就绪标志发布给 Wi-Fi 任务；最终版本已重跑该测试及 ESP32 干净构建。测试只替换 Wi-Fi/RTOS API 和配对头，不替换分发实现。
- 原 `remote/tools/test.ps1` 的协议/server/client **100,200** 项断言、实际 energy_master、DBUS 解码和 UART 分发检查通过；原 C 板业务、DBUS 控制边界、灯板 CAN 和 UART 协议未修改。
- UI 的七种状态 × 五个页面 × 电机显示开关共 **70 张**原生 240×320 画面通过字形/标签边界检查。以 `596b900` 原源码、原字体渲染为参考，关闭电机显示时 **35 张完全逐像素一致**；开启时另 **35 张**在电机文字区域 `(8,231)..(231,248)` 和电机就绪条件的开始按钮状态外完全一致。三个字号各 235 个原有字形的位图、字距及偏移均不变。

UI 只增加控制页/设备页空白处的电机状态，没有移动卡片、导航或按钮。上述画面对照不代表实体触摸命中验证，也不继承其他布局版本的触摸结论。原始图像和结果在 `remote/build/motor-now-20261031/ui-current/`、`ui-baseline/`、`ui-comparison.json`，当前预览在 `remote/docs/motor-now-ui/`。

## 身份与验收边界

本轮仅经 USB 读取新设备身份：COM45、ESP32-C3 QFN32 rev0.4、4 MB Flash、MAC `9C:96:D5:B1:65:EC`。屏幕使用已确认的 `70:4B:CA:2F:02:50`，原 XIAO S3 配对配置不变。F1 `motor_control.c` 及速度、PID、补偿初始化值与原版本完全一致。远程 UART/启动身份初始化失败只禁用远程，本地按键仍可运行。
