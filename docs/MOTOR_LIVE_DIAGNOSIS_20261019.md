## 关于不均匀负载补偿

建议采用“按实际机关角度的重力前馈 + 速度 PID”，大符再考虑目标加速度前馈。一般单轴刚性偏重机构的重力项可用 `A*sin(theta)+B*cos(theta)` 表示，系数含幅值和零位相位；惯量项与角加速度有关。模型依据：[MIT 单摆动力学](https://underactuated.mit.edu/pend.html)，控制结构参考：[MathWorks 重力补偿与反馈控制](https://www.mathworks.com/help/robotics/ug/joint-space-motion-model.html)。

当前代码仅保留 `feedback.encoder` 单圈值，没有多圈累计及输出轴零位。实现前需要：

1. 核实皮带传动比；按每次新鲜 CAN 反馈累计电机编码器转角，换算输出轴角度，检测丢帧造成的角度歧义。
2. 定义机械零位或受控标定流程。断电重启、跟踪失效和皮带打滑后不能沿用未经重新确认的补偿相位。不能用大符正弦目标的时间相位代替机械角度。
3. 小符恒速多圈采集角度、电流、速度与加速度，辨识重力/摩擦项；再验证大符的惯量补偿。现有 50 ms 主机记录不足以可靠恢复电机编码器跨圈，不直接把这些记录拟合成可烧录参数。
4. 前馈与 PID 合成后统一限幅，并处理积分饱和；停止、失联、角度失效时关闭补偿输出，继续保持手动重新启动的规则。
5. 如果重力与加速所需扭矩超过现有电流上限，先评估机械配重和传动，前馈本身不能增加可用最大扭矩。

本节为基于实测和源码的实施建议，未宣称补偿已加入或完成实物验证。
