# slave2：12 MHz 晶振配置

2026-10-31 按用户要求，只将 slave2 配置为 12 MHz 外部晶振。`feature/esp32-screen-remote` 和 `fu_clion` 两个现有分支均已同步。未烧录或复位任何板卡。

配置：`HSE_VALUE=12000000U`，PLL ×6，HSE 不分频，AHB 不分频，APB1 ÷2。因此在实际 12 MHz 硬件上，HCLK 为 72 MHz、PCLK1 为 36 MHz；原 CAN 参数仍对应 1 Mbps，TIM2/TIM3 的原 PWM 参数仍对应 800 kHz。slave1、slave3～slave5 保留原 8 MHz 时钟配置。

每个分支只改 slave2 的三个文件：

- `Core/Inc/stm32f1xx_hal_conf.h`：外部晶振频率改为 12 MHz。
- `Core/Src/main.c`：PLL 从 ×9 改为 ×6。
- `fu_wan_clion.ioc`：同步 HSE、PLL 与时钟树元数据，避免 CubeMX 再生成时恢复旧设置。

## 构建与核验

- 两分支 `slave2-Debug` 干净构建通过。
- 实际预处理 `system_stm32f1xx.c` 和 HAL RCC 驱动，均得到 `HSE_VALUE=12000000U`，没有命令行宏覆盖。
- 修改前后的指纹核对确认，其他从机时钟文件和各板 CAN、TIM 文件未变化。
- 主工作区固件 Flash 23,096 B，CLion 工作树固件 Flash 23,076 B；两者 RAM 均为 18,528 / 20,480 B。两分支原有业务版本不同，不能要求其 bin 摘要相同。
- 详细构建日志、修改前备份和摘要在 `build/slave2-12mhz-20261031/`。

## 使用

CLion 选择 `STM32-slave2-Debug`，目标 `EnergyFirmware_slave2_Debug`。

当前 CLion 工作树候选固件：`.worktrees/fu_clion/build/slave2-Debug/EnergyFirmware.elf`；同目录有 hex、bin。SHA256（bin）：`1fca62a9e3f69563031435d29784bbbcdc2dd012f31069a0cadafd64360fde77`。

主工作区候选固件：`build/slave2-Debug/EnergyFirmware.elf`；SHA256（bin）：`3db26acfa0c576a18c0eaefa24b0fb5324d0cc36e6ecf9b117df6ceb42cd315c`。

这是 **2 号节点、12 MHz 板专用**固件：点亮 ID 为 `0x211`，单板关闭为 `0x212`，击打反馈为 `0x311`，全局关闭仍为 `0x2FF`。不要把它当作 1 号节点的 `0x201` 固件。

本轮只完成源代码配置与构建。下载后还需实际核对一秒约 1000 个 `uwTick`、CAN 接收/错误状态，以及 C 板选择 2 号板时的真实灯效。
